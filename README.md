> Некоторые антивирусные программы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл может быть удалён и отправлен в карантин. Обычно детект содержит название `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA - потенциально нежелательных приложений. Если вы уверенно умеете настраивать исключения, лучше добавить необходимое исключение; при отсутствии такой уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите пункт "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", затем выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку провайдер Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы - [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно активировать в настройках параметр "Транзит запросов". Если его выключить, Secure DNS на компьютере может работать некорректно

2. Получите архив zip/rar на [странице последнего релиза](https://github.com/LookoutLegislator/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip данный пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - запуск выбранной стратегии вручную

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты - ALT, FAKE и другие, пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и прочих служб, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию нужно запустить заново.**  
  В скобках показывается, включена функция или выключена.
  - **`IPSet Filter`** - изменение режима обработки ресурсов из `ipset-all.txt`.  
  Этот пункт полезен при диагностике, когда ресурс без zapret доступен, а с ним - нет.  
  В скобках отображается текущее состояние:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сопоставляются со списком
    - `any` - фильтруется любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret может не запускаться или работать неправильно.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы клиента
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, процесс обхода winws.exe должен появиться в панели задач.  
Если его нет, обратитесь к [#522](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните в ней по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/LookoutLegislator/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Рабочие стратегии могут устаревать.**
> Иногда выбранная стратегия работает определённый период, а затем перестаёт действовать после её обнаружения.
> В этом репозитории собрано много вариантов обхода. Если ни один не даёт результата, создайте собственную стратегию на базе одной из имеющихся и измените её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что нужный адрес присутствует в списках доменов или IP

- Переключитесь на другие стратегии, например **`ALT`**, **`FAKE`** и остальные

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните ресурсы и данные, добавленные вами вручную
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдутся ошибки, исправьте их, затем в конце выберите Y
- Удалите старую папку с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/LookoutLegislator/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска; в пути не должно быть пробелов и специальных символов
- Поочерёдно проверяйте различные скрипты `general`. Если сайты не открываются, закройте программу через значок замка в панели задач и запустите другую стратегию
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- Откройте service.bat и проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не планировали затрагивать.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Сначала определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Попробуйте остальные стратегии, особенно если раньше доступ уже работал.
- Также смотрите [#251](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Через `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия доступна, можно временно пользоваться ей.
- Если Discord не работает и в браузере, повторно проверьте все стратегии. Случается, что на одной стратегии YouTube доступен, а Discord - нет.
- Дополнительное обсуждение: [#252](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/LookoutLegislator/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры или нет сетевого доступа в них

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и активировать `Game Filter`
- если это не помогло, дополнительно включить `ipset any`

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящего решения

- Опишите проблему [здесь](https://github.com/LookoutLegislator/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например если IP всей сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
